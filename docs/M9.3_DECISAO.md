# M9.3 — Decisão: endpoint /api/v1/eval/ultima-execucao

## Contexto

M9.3 foi introduzido em M0 (`7dc3d4b`) e restaurado em `c3ec0fc`. O
critério em `MILESTONES.md` usa a forma `/api/v1/eval/ultima-execucao`.
O `CONTRATO_API.md` §Eval mantém a forma pré-restauração `GET
/eval/ultima-execucao`, que é inconsistente com o padrão de `main.py`
(todos os routers usam `prefix="/api/v1/<recurso>"`).

O runner de eval (`backend/src/caixaclaro/eval/runner.py`) produz a
`Metricas` dataclass mas não persiste. O endpoint não existe.

## Decisão

1. Path canônico: `GET /api/v1/eval/ultima-execucao`.
   `CONTRATO_API.md` §Eval será corrigido.

2. Persistência: arquivo JSON em disco, caminho configurável por
   `settings.eval_ultima_execucao_path`. Produzido pelo runner.
   O endpoint apenas lê — não recalcula.

3. Escrita: o runner ganha `--publicar <caminho>` opcional. Sem o
   argumento, o comportamento atual (imprimir e sair) é preservado.

4. Schema: derivado de `Metricas`. Campos:
   executado_em, commit, taxonomia_version, total, avaliaveis,
   abstratidos, metricas{A,B,C,D}, por_dificuldade, resultado.

5. Sem autenticação. 404 se o arquivo não existir.

## Fora de escopo

- M9.4 Bateria A–H: continua bloqueado.
- Sincronização CI↔produção: pertence ao M10 (Deploy).
